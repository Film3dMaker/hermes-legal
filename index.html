Política de Privacidad

Aplicación: Hermes NexoShape · Responsable: Balarama Muñoz (NexoShape) · Última actualización: 8 de noviembre de 2026

Resumen en una línea: esta aplicación es una herramienta personal de automatización que solo accede a las cuentas de Google de su propio responsable. No tiene usuarios externos, no vende ni comparte datos con terceros y no opera servidores que almacenen información de otras personas.

1. Qué es esta aplicación

Hermes NexoShape es un cliente OAuth de uso estrictamente privado, registrado en el proyecto de Google Cloud myhermes-504305. Lo utiliza un único titular —su propietario— para que sus propios agentes de software consulten y organicen información de su cuenta de Google. No se distribuye al público ni admite registro de usuarios.

3. Dónde viven los datos

Toda la información se procesa y almacena localmente, en el equipo del titular (MacBook propio). Los tokens de acceso se guardan cifrados por el sistema de archivos con permisos restringidos. No existe un backend propio, ni base de datos remota, ni servicio en la nube operado por el responsable de esta aplicación.

4. Con quién se comparte

Con nadie. No hay transferencia, venta, cesión ni uso publicitario de los datos obtenidos mediante las API de Google. El único tratamiento ocurre dentro del equipo del titular, por procesos que él mismo ejecuta.

5. Conservación y eliminación

Los datos permanecen en el equipo del titular mientras él los conserve. La revocación del acceso se hace en cualquier momento desde myaccount.google.com/permissions, lo que invalida los tokens de inmediato. El titular puede además borrar los archivos locales cuando quiera.

6. Uso limitado de datos de usuario de Google

El uso que esta aplicación hace de la información recibida de las API de Google se ajusta a la Política de Datos de Usuario de los Servicios API de Google, incluidos sus requisitos de uso limitado. Los datos no se emplean para entrenar modelos de terceros ni para publicidad.
